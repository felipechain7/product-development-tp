# Parking Log

Registro de estacionamiento para seguimiento de entradas y salidas.

| Fecha | Hora entrada | Hora salida | Matrícula | Ubicación | Duración | Observaciones |
|-------|--------------|-------------|-----------|----------|----------|---------------|
| 2026-08-10 | 09:00 | 11:30 | ABC-1234 | Nivel -1, Sector A | 2h30m | Ejemplo: pago en máquina 3 |

## Cómo usar
- Añade una fila por cada entrada/salida.
- Usa el formato ISO para fecha (YYYY-MM-DD) y 24h para la hora.
- Completa observaciones si hay incidencias (p.ej. multa, daño, etc.).

## Resumen mensual (opcional)
Puedes añadir aquí un resumen mensual de ocupación, ingresos o incidencias.
